## 📸 تحويل إلى صورة JPG

### الخيار 1️⃣: أداة أون لاين (الأسهل)
1. اذهب إلى: https://htmltoimage.com
2. انسخ كود HTML من الملف
3. اضغط "Convert to Image"
4. احفظ كـ JPG

### الخيار 2️⃣: استخدام Puppeteer (للمطورين)
```bash
npm install puppeteer
```

```javascript
const puppeteer = require('puppeteer');

(async () => {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  await page.goto('file:///path/to/job-announcement.html');
  await page.screenshot({
    path: 'job-announcement.jpg',
    fullPage: true,
    type: 'jpeg',
    quality: 95
  });
  await browser.close();
})();
```
